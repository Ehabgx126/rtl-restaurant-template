# قالب ديوان RTL — قالب مطعم عربي احترافي جاهز للبيع

> **Diwan RTL — Premium Arabic Restaurant Landing Page Template**
> صفحة هبوط كاملة بالعربية (RTL) لمطاعم والمقاهي — HTML/CSS/JS نقي بدون أي مكتبات ثقيلة.

عرض حي مباشر: https://ehabgx126.github.io/rtl-restaurant-template/

---

## لماذا هذا القالب؟

قوالب المطاعم العربية RTL شبه معدومة في السوق، بينما الطلب عليها ثابت من أصحاب المطاعم والمقاهي في السعودية والخليج. هذا القالب جاهز للتسليم للعميل بعد تعديل بسيط، أو للبيع كقالب جاهز على منصات مثل Gumroad و khamsat و مستقل.

## المميزات

- **عربي 100% RTL** بخط Tajawal من Google Fonts
- **قائمة طعام تفاعلية** مع فلترة (مشاوي / مقبلات / حلويات / مشروبات)
- **نموذج حجز طاولة** مع تحقق من البيانات ورسالة نجاح جاهزة للربط بـ Formspree
- **زر واتساب عائم** مربوط برابط wa.me لاستقبال الطلبات مباشرة
- **عدّادات رقمية متحركة** في الواجهة الرئيسية
- **حركات ظهور ناعمة** عند التمرير (IntersectionObserver)
- **متجاوب بالكامل** مع الجوال والتابلت (3 نقاط توقف)
- **بدون أي إطار عمل** — HTML/CSS/JS نقي، تحميل فوري وسرعة عالية
- **كود منظم ومعلّق بالعربية** ليسهل تعديله أو تسليمه للعميل

## هيكل الملفات

```
rtl-restaurant-template/
├── index.html          الصفحة الكاملة (7 أقسام)
├── css/
│   └── style.css       التنسيقات + متغيرات الألوان في :root
├── js/
│   └── main.js         التفاعلات الستة معلقة بالعربية
├── README.md           هذا الملف
└── LICENSE.md          ترخيص الاستخدام
```

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر محلي:

```bash
# بايثون
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## دليل التخصيص (للمشتري)

| ماذا تريد تغييره؟ | أين؟ |
|---|---|
| الألوان | متغيرات `:root` أعلى `css/style.css` — غيّر `--primary` و `--dark` فقط |
| اسم المطعم | ابحث عن "الديوان" في `index.html` واستبدله |
| الأطباق والأسعار | قسم `menu-grid` في `index.html` — كل طبق بطاقة مستقلة |
| رقم الواتساب | ابحث عن `wa.me/966500000000` واستبدلها برقمك |
| رقم الهاتف والعنوان | قسمي الحجز والتذييل |
| ربط النموذج ببريدك | التعليمات داخل `js/main.js` القسم 6 (Formspree مجانًا) |
| صور حقيقية بدل الخلفيات | استبدل عناصر `menu-thumb` و `g-item` بوسم `<img>` |

## فكرة الإصدار التجريبي المجاني (Demo)

لزيادة المبيعات: ارفع نسخة حية من القالب عبر **GitHub Pages** (دقيقة واحدة):

1. Settings → Pages → Source: فرع `main` → مجلد `/ (root)`
2. ستحصل على رابط مثل `https://ehabgx126.github.io/rtl-restaurant-template/`
3. ضع الرابط في هذا الـ README وفي صفحة البيع — المشتري يرى المنتج قبل الدفع ويتحول بسهولة
